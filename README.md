# Dolor — قیمت دلار بازار آزاد تهران

داشبورد فارسی رایگان قیمت دلار بازار آزاد تهران با واحد ریال/تومان، با **دو حالت**:

1. **GitHub Pages مستقل**: GitHub Actions هر ۵ دقیقه (گاهی دیرتر) از نرخ‌سنج و در صورت خطا از Iran Market Data می‌خواند و فایل عمومی `/data/dollar.json` را منتشر می‌کند. درخواست‌های کاربران فقط به فایل منتشرشدهٔ Pages می‌رسند؛ در نتیجه به منبع قیمت فشار وارد نمی‌کنند. **این حالت دقیقه‌ای یا لحظه‌ای نیست.**
2. **GitHub Pages + Cloudflare Workers (برای نرخ یک‌دقیقه‌ای)**: یک Worker رایگان با Durable Object دارای کش مشترک سراسری کار می‌کند و حداکثر یک بار در هر ۶۰ ثانیه منبع رایگان نرخ‌سنج را می‌خواند. بازدیدکنندگان می‌توانند هر دقیقه پاسخ بگیرند. این حالت نیاز به استقرار Worker در حساب رایگان Cloudflare دارد.

## راه‌اندازی حالت GitHub Pages

از مسیر **Settings → Pages → Build and deployment → Source** گزینهٔ **GitHub Actions** را انتخاب کنید.

Workflow پروژه با نام **Publish Dollar Dashboard** برای push، اجرای دستی و زمان‌بندی هر ۵ دقیقه تنظیم شده است. در صورت لزوم از تب **Actions** آن را دستی اجرا کنید.

> طبق مستندات GitHub، اجرای زمان‌بندی‌شده حداقل فاصلهٔ ۵ دقیقه دارد؛ ممکن است اجرا یا انتشار با تأخیر انجام شود. GitHub Pages هاست استاتیک است و به تنهایی API پویا در هر ثانیه ایجاد نمی‌کند.

## فعال‌سازی نرخ یک‌دقیقه‌ای با Cloudflare Workers (اختیاری)

برای داشتن API با کش مشترک و **۶۰ درخواست کاربران در دقیقه**، یک حساب Cloudflare Workers Free بسازید. Node.js موردنیاز است.

در پوشهٔ پروژه:

```bash
npx wrangler login
npx wrangler deploy
```

این کد، Worker و Durable Object با SQLite storage را مطابق `wrangler.toml` مستقر می‌کند. پس از استقرار، URL پیش‌فرض را از خروجی Wrangler بردارید. نمونهٔ قالب نشانی:

```text
https://dolor-dollar-api.YOUR-SUBDOMAIN.workers.dev/api/dollar
```

سپس در فایل `config.json`، فیلد `live_api` را با **آدرس واقعی** کامل Worker جایگزین کرده و commit کنید:

```json
{
  "live_api": "https://dolor-dollar-api.YOUR-SUBDOMAIN.workers.dev/api/dollar"
}
```

در این حالت سایت GitHub Pages از API Worker استفاده می‌کند. **تا زمان تنظیم `config.json`، حالت عادی Pages فعال می‌ماند.**

### نمونهٔ خروجی Worker

```json
{
  "price_irr": 2500000,
  "price_toman": 250000,
  "unit": "IRR",
  "source": "nerkhsanj",
  "market_date": "1405/07/25",
  "market_time": "13:01",
  "fetched_at": "2026-10-17T09:31:00.000Z",
  "stale": false
}
```

**این مقادیر فقط مثال ساختار JSON هستند و نرخ واقعی بازار نیستند.**

## محدودیت‌ها و مسئولیت‌پذیری

- نرخ‌سنج بدون کلید و بدون ثبت‌نام دادهٔ بازار آزاد تهران را با به‌روزرسانی اعلام‌شده هر یک دقیقه ارائه می‌کند؛ شرایط منبع می‌گوید هر endpoint را **حداکثر یک بار در دقیقه** بخوانید و هنگام نمایش نام «نرخ‌سنج» را بیاورید.
- Worker از یک **Durable Object ثابت و مشترک برای تمام کاربران** استفاده می‌کند تا فراخوانی‌ها را بین تمام مشتریان هماهنگ کند. این کد تلاش می‌کند فاصلهٔ درخواست‌های منبع را ۶۰ ثانیه نگه دارد؛ دسترس‌پذیری و تازگی واقعی به منبع وابسته است.
- پلن رایگان Workers و Durable Objects هرکدام محدودیت **۱۰۰٬۰۰۰ درخواست روزانه** دارند (به‌علاوهٔ محدودیت‌های دیگر). ۶۰ درخواست در دقیقه به‌صورت پیوسته برابر **۸۶٬۴۰۰ درخواست در روز** است؛ در صورت بار بیشتر یا استفاده از Workerهای دیگر ممکن است سهمیه تمام شود. هیچ SLA رایگانی تضمین نشده است.
- اگر منبع در دسترس نباشد، کد **قیمت جدید جعل نمی‌کند**؛ مقدار کش قدیمی با `stale: true` برمی‌گردد یا در صورت نبود هیچ قیمت معتبری خطای 503 می‌دهد.
- هر دو روش نیازمند تأیید عملی استقرار و دسترسی شبکه از منطقهٔ استقرار هستند؛ نمی‌توان بدون راه‌اندازی، کارکرد مداوم را تضمین کرد.
- قیمت دلار بازار آزاد یک مشاهدهٔ بازار است، نه تضمین خریدوفروش. مسئولیت مجوز بازنشر و استفادهٔ تجاری داده با توسعه‌دهنده است.

## فایل‌ها

| مسیر | کاربرد |
| --- | --- |
| `index.html` | صفحهٔ واکنش‌گرای فارسی |
| `config.json` | URL اختیاری Worker |
| `worker/index.js` | API لحظه‌ای و کش مشترک Durable Object |
| `wrangler.toml` | پیکربندی استقرار Cloudflare |
| `scripts/build_data.py` | ساخت JSON استاتیک برای Pages |
| `.github/workflows/pages.yml` | واکشی و انتشار هر ۵ دقیقه |
| `data/dollar.json` | قالب اولیه؛ خروجی واقعی هنگام Deploy ساخته می‌شود |
